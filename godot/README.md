# Nightshift: District Run

A standalone Godot 4 open-city driving game project. The city is generated from original procedural geometry; the project includes no external assets or add-on dependencies.

## Run it

1. Install Godot 4.3 or later.
2. Unzip the project folder.
3. In Godot, choose **Import** and select `project.godot`.
4. Press **F6** or **F5** to play.

## Controls

- **W / Up Arrow:** accelerate
- **S / Down Arrow:** reverse
- **A / D / Left / Right:** steer
- **Space:** handbrake
- **E:** complete a delivery when close to the glowing marker
- **Esc:** pause

## Included systems

- Procedurally built 7 × 7 city district, plaza, park, lit buildings, road grid, and minimap
- Third-person driving with acceleration, reverse, steering, braking, and chase camera
- Moving ambient traffic
- Five rotating courier contracts with increasing rewards
- Police attention, pursuit vehicles, and cash penalties
- On-screen contract, cash, wanted level, speed, and controls

This is an original playable project and does not contain GTA 6 code, maps, characters, missions, or assets.
