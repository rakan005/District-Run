# Nightshift: District Run

An original open-city night driving game. Play in a desktop browser through GitHub Pages once the Pages workflow finishes deploying.

## Browser game

Open `web/index.html` or visit the GitHub Pages link in the repository description after deployment. No build tools or external game assets are required.

## Controls

- WASD or arrow keys: drive
- Space: handbrake
- E: deliver near the glowing objective
- Esc: pause

## Godot project

The `godot/` folder contains the standalone Godot 4 project. Import `godot/project.godot` in Godot 4 and press F5.

The city, game title, characters, and assets are original. This repository is not affiliated with Rockstar Games and does not contain GTA 6 assets or code.
