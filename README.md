# Nightshift: District Run

An original open-city night driving game.

## Play online

The browser version is at **https://rakan005.github.io/aa/** after GitHub Pages is enabled for this repository under **Settings → Pages → Build and deployment → Source: GitHub Actions**.

## Controls

- WASD or arrow keys: drive
- Space: handbrake
- E: deliver near the glowing objective
- Esc: pause

## Godot project

The `godot/` folder contains the standalone Godot 4 project. Import `godot/project.godot` in Godot 4 and press F5. A downloadable project archive is in `downloads/`.

The city, game title, characters, and assets are original. This repository is not affiliated with Rockstar Games and does not contain GTA 6 assets or code.
